## 第一部分：产品方案

### 产品定位

专为 1:1 方形小屏智能手表打造的**完全本地**五子棋对弈应用。无服务器、无账号、无广告、不申请任何权限（Manifest 未声明 `INTERNET`，从系统层面杜绝联网可能）。

### 用户流程

```text
启动页（Logo，700ms）
  → 首页
     ├─ 单人对弈 → 模式选择页 → 难度选择页（难度 + 先后手 + 棋盘大小）→ 对局页
     ├─ 多人对弈 → 对局页（同屏轮流）
     ├─ 继续游戏 → 对局页（从自动存档恢复）
     ├─ 设置（16 项偏好）
     ├─ 棋谱记录（最近 20 局）
     └─ 关于
对局页：顶部状态区 → Canvas 棋盘（缩放/拖动/吸附落子）→ 底部操作区
  ├─ 胜/和 → 结果面板（再来一局 / 返回首页 / 查看棋谱）
  ├─ 暂停 → 暂停遮罩（继续 / 保存并退出）
  └─ 返回键 → 退出确认（自动保存）
```

### 主要功能

| 功能 | 实现 |
| --- | --- |
| 单人模式 | 玩家执黑 / 执白 / 随机；AI 自动落子 |
| 多人模式 | 同屏轮流，"黑方落子/白方落子"明确显示，可选换手遮挡棋盘 |
| 练习模式 | 无胜负？否——保留胜负判定但提供建议落点 + 清空棋盘，自由摆棋 |
| AI 难度 | 入门 / 简单 / 普通 / 困难 / 专家 / 自定义（深度·时间·随机性） |
| 棋盘缩放 | 双指捏合（以手指中点为中心）+ ＋/−/适应/居中 四按钮，1.0~3.0 |
| 棋盘拖动 | 缩放后单指拖动，边缘钳制不会完全拖出屏幕 |
| 撤销 | 多人撤 1 手；单人撤"玩家+AI"两手；配额 不限/1 次/3 次/关闭 |
| 重开/暂停/继续 | 均支持；暂停自动保存并取消 AI 搜索 |
| 自动保存 | 每次落子、暂停、进入后台、退出时保存；结束后清除 |
| 棋谱 | 最近 20 局：时间/模式/难度/结果/步数/时长 |
| 深色模式 | 跟随系统 / 浅色 / 深色 |
| 高对比模式 | 纯黑底 + 亮黄棋盘线 + 青色标记，黑白子加描边 |

### 小屏适配设计

- **无写死像素**：布局全部 `dp/sp` + 权重；棋盘尺寸由父容器实测尺寸决定；
- **区域比例**：顶部状态区 ~12%、棋盘区 68%、底部操作区 ~20%（权重实现，随内容自适应）；
- **安全区域**：根布局 `WindowInsets.safeDrawing` 内边距，圆角/表冠区域不遮挡；
- **触达**：全部按钮 ≥40dp（操作按钮 40dp，主按钮 46dp，缩放按钮 40dp）；
- **落点吸附**：点击自动吸附最近交叉点，配合缩放降低误触；
- **字体缩放**：文字全部 `sp`，跟随系统字体缩放。

### AI 难度设计

| 难度 | 策略 |
| --- | --- |
| 入门 | 立即取胜点 → 拦截对手成五 → 邻域随机落子 |
| 简单 | 立即取胜点 → 拦截 → 前 3 个启发式最优中随机 |
| 普通 | 2 层搜索，24 候选，1.2s 预算，5% 随机 |
| 困难 | 4 层迭代加深，14 候选，≤3s 预算 |
| 专家 | 8 层迭代加深 + 置换表，12 候选，思考时间可在设置中调整（1/3/5/8s） |
| 自定义 | 搜索深度（2/3/4/6/8 层）+ 随机性（0/20/50%）+ 思考时间 |

## 第二部分：技术架构

### 模块划分与数据流

```text
UI (Compose, 只读 GameState 渲染 + 事件回调)
        │ 用户事件 / 状态订阅
        ▼
GameViewModel (编排：落子、AI 调度、悔棋、暂停、存档)
        │ 领域调用
        ▼
Domain 层（纯 Kotlin，无 Android 依赖）
├── Board          可变棋盘 + 落子栈（撤销/回放）
├── GomokuRules    五连/长连/和棋/禁手（简化棋型）
├── UndoPolicy     悔棋策略
├── Evaluator      棋型评分（提示词分值表）
├── MoveGenerator  候选点（邻域 + 攻防启发式排序）
├── SearchEngine   Alpha-Beta(负极大) + 迭代加深 + Zobrist + 置换表 + 超时
└── AiPlayer       难度路由
        │
        ▼
Data 层
├── SettingsStore   DataStore（防御性读取，坏值回退默认）
├── GameSaveStore   autosave.json（kotlinx-serialization，损坏返回 null）
└── MatchHistoryStore history.json（最多 20 局 + StateFlow）
```

- **状态管理**：`GameUiState`（含不可变 `GameState` 快照）经 `StateFlow` 下发；棋盘缩放/偏移为独立 Compose 状态（`BoardViewState`），手势高频更新只重组绘制层；
- **AI 执行**：`viewModelScope.launch` → `withContext(Dispatchers.Default)`；搜索内部对棋盘**副本**操作（超时中断也不会污染对局棋盘）；`isActive` 取消信号 + 时间预算双重中断；超时返回当前最佳着法；
- **性能**：Canvas 单节点绘制全部棋子（无逐子 Composable）；候选点宽度限制；置换表 25 万条上限自动清空；存档写入 300ms 节流；`onStop` 释放 AI 任务。

### 测试方案

- **单元测试（7 组，纯 JVM）**：棋盘初始化、合法/重复/越界落子、横纵双对角五连、长连两种口径、和棋（3×3 满盘）、悔棋策略、AI 立即取胜/拦截/耗时上限、棋型分值表、存档序列化往返与损坏防御、坐标转换与缩放后落点、禁手用例；
- **UI 测试（2 组，需设备）**：首页按钮与导航；多人模式落子 → 换手 → 悔棋回退。

### 文字缩放实现方式

设置页滑块（80%~150%，10% 步进，实时显示百分比，独立“恢复默认”按钮）→ UiSettings.fontScale → DataStore 持久化（重启保留）→ GomokuTheme 中 `LocalDensity.fontScale = 系统 fontScale × 用户 fontScale`，**所有 sp 文字一处生效**（含标题/按钮/状态/设置项）；关键控件高度经 scaledDp(基准 dp) 随缩放自动增高防裁切；棋盘内序号/坐标为绘制文字，除以 pixelPerSp 保持像素恒定，不随全局缩放溢出格子。拖动滑块即时重组预览，无需重启。

### 圆角安全区域实现方式

`rememberWatchSafeArea()`：cornerInset = 屏幕宽度 × 6%（240 屏 ≈ 14dp、390 屏 ≈ 23dp），动态计算不写死像素；`Modifier.watchSafePadding()` 取调用方期望值与圆角内缩的较大者，应用于：对局页根布局、全部滚动内容容器、屏幕标题行、首页列表、换手遮罩。缩放按钮从棋盘右上角移至**棋盘右缘垂直居中**，不再贴近圆角。

### 按钮布局调整说明

- 首页/模式/难度等主要按钮：纵向居中、大圆角矩形、宽度撑满安全区；
- 对局底部操作栏：四按钮底部中央排布于安全区内，紧凑模式只显示图标（保留 contentDescription）；
- 全部按钮 `heightIn(min = scaledDp(基准))`：40~46dp 基准随文字放大自动增高，文字 maxLines=1；
- 状态栏紧凑模式隐藏次要的双方身份行，优先当前回合与棋盘空间；
- 棋盘 Box 由固定权重 0.68 改为 weight(1f)：状态栏/操作栏按内容增高，棋盘自动占据剩余全部空间不被挤压；
- **缩放按钮收纳化（v1.0.3）**：棋盘上平时只显示一个半透明 40dp 切换钮（右缘垂直居中），
  点击才浮出 ＋/−/适/中 面板，5 秒无操作自动收起，点“适应屏幕”后立即收起，
  双指捏合手势不受影响，解决常驻面板遮挡棋盘视野的问题。

#### 高斯模糊实现方式

两层结构：底层纵向渐变背景 + 中层两团低透明度光晕（primaryContainer/secondaryContainer 35%）；
光晕用 `Modifier.blur(40dp)`（API 31+ RenderEffect）；**API 26~30 自动无实时模糊，
直接静态径向渐变（零额外渲染负担，即降级方案）**；前景标题与按钮不模糊；
“减少动态效果”时光晕静止（12s 缓动漂移停用）。

#### 动画曲线和时长配置

- 主页进入：逐项 fadeIn+slideIn 350ms，错峰 60ms，EaseOutCubic；
- 按钮按下：scale 1→0.97，120ms EaseOutCubic；
- 页面切换：enter 220ms fade+slide(it/20)，exit 160ms fade，EaseOutCubic；
- 光晕漂移：12000ms 往复 FastOutSlowIn；
- 全部动画在“减少动态效果”下降级为 1ms（仅保留淡入淡出）。

#### 加载页面改进内容与初始化流程

动画不变（落子成局）+ 新增：
1. “正在准备棋局”三点呼吸提示（减少动效时静态）；
2. 真实初始化与动画并行：IO 后台依次 加载本地设置（预热 DataStore）→ 探测可恢复棋局；
3. 动画播完 + 初始化完成 + 250ms 停留 → 平滑进入主页（动画即最短显示时长，防闪烁）；
4. 初始化失败：显示“初始化失败”+ 重试按钮（不展示技术堆栈），错误时禁用跳过。

#### 圆角安全区域处理方式

沿用统一的 watchSafePadding（屏幕宽 × 6% 内缩）：主页根布局、启动页品牌声明、标题行、
滚动容器共用一套；光晕装饰可延伸至边缘，交互控件全部在安全区内。

#### 不同屏幕尺寸测试结果

字号/按钮/安全区均为比例制 + sp + heightIn，240~390 全系列自适应；
<250dp 宽自动降一档字号与间距（真机逐尺寸目视验收仍建议进行）。
